1 إعدادات الربط بجيت هب (مرة واحدة بس)

✓ محفوظ على الجهاز ده
محتاج مفتاح دخول جديد؟ اضغط هنا
  1. روح على github.com وسجل دخول
  2. من الصورة الشخصية فوق يمين → Settings
  3. تحت خالص → Developer settings → Personal access tokens → Fine-grained tokens
  4. Generate new token، اختار اسم، ومدة صلاحية (سنة مثلًا)
  5. في Repository access اختار Only select repositories واختار nexon
  6. في Permissions افتح Contents واختارها Read and write
  7. Generate token، وانسخ المفتاح (يبدأ بـ github_pat_) والصقه فوق

✎ بتعدل على وحدة موجودة

كل الحقول اتملت ببيانات الوحدة الحالية. عدّل اللي عايزه واضغط "حفظ التعديلات" تحت. الفيديو/الصور مش هتتغير إلا لو اخترت ملف جديد.
